# Security Policy

## Supported version

Only the current deployment from `main` is supported.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting feature for this repository. Include the affected URL or commit, reproduction steps, impact, and any suggested mitigation.

This is a static client-only demonstration. It stores attempt progress in browser local storage and deliberately ships its question data and answer key in the public bundle. Answer-key visibility is a documented product limitation, not a vulnerability.
